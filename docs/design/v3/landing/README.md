# Лендинг v3

Макет из Claude Design (этап 3, промпт — [prompt-landing.md](../../../archive/claude-design/prompt-landing.md)). Реализует задача **E39-35**.

Холст: https://claude.ai/artifact/J2k6kkprKsA2ruwY74YJES (артборды `land_*`). Всё ниже открывается в браузере напрямую.

| Файл | Что |
|---|---|
| [landing.html](landing.html) | **Рабочая страница** — адаптивная (перелом на 860 px), светлая и тёмная темы, все анимации живые. Эталон для реализации |
| [spec.html](spec.html) | **Спецификация** с холста: переходы T1–T6, анимации A1–A10 с таймингами и кривыми, выбор заголовка, тема и доступность |
| [annot-1440.html](annot-1440.html), [annot-375.html](annot-375.html) | Страница с пометками: оранжевые A1–A10 — где какая анимация, тёмные плашки T1–T6 — куда ведёт элемент (пометки не часть продукта) |

## Переходы (spec.html)

| | Элемент | Куда |
|---|---|---|
| T1 | «Пройти тест» (hero и финальный призыв) | `/register?role=candidate` → сразу поток теста, без промежуточных экранов (E39-6) |
| T2 | «Ищу сотрудников» (hero и финальный призыв) | `/register?role=employer` → онбординг компании (E39-7) |
| T3 | «Войти» (шапка) | `/login`, один для всех ролей |
| T4 | «Как это работает», «Доверие», «ФСП» (шапка) | Плавная прокрутка к блоку, 500 мс ease-in-out |
| T5 | «Условия», «Политика ПДн», «Контакты» (подвал) | Статичные страницы-заглушки |
| T6 | «Демо для жюри» (мелкая ссылка в подвале) | Демо-режим, только при `VITE_JURY_MODE=true`; в шапке и hero её нет |

Других переходов нет: карточки и иллюстрации не кликабельны.

## Анимации (spec.html)

| | Что | Когда | Длительность | Кривая |
|---|---|---|---|---|
| A1 | Прилёт карточки приглашения из `translate(56px,-36px) rotate(-5deg) scale(.96)`; вторая карточка следом; плашки «Новое приглашение» и «Совпадение 92» выскакивают; красная точка пульсирует | При загрузке: основная через 150 мс, вторая +270, плашки +650 и +800 мс | 800 мс (opacity 500); плашки 400 мс; пульс 2,4 с по кругу | `cubic-bezier(.16,1,.3,1)`; плашки `(.34,1.56,.64,1)` |
| A2 | Параллакс иллюстрации: три слоя (0,03 · 0,06 · 0,09 от прокрутки), не больше 24 px | Прокрутка hero, только шире 860 px | requestAnimationFrame | линейно |
| A3 | Появление блоков: opacity 0 → 1, сдвиг 16 px, каскад 60–80 мс | Видно 15 % блока, один раз | 600 мс | `cubic-bezier(.2,.7,.2,1)` |
| A4 | Подложка вкладки «Кандидату / Компании» перетекает (сдвиг и ширина) | Клик или ← → | 280 мс | `cubic-bezier(.4,0,.2,1)` |
| A5 | Шаги нового сценария выезжают на 8 px каскадом, линия вычерчивается слева направо | Сразу после A4 | шаги 240 мс (+60 каскад); линия 500 мс | ease-out; линия `(.4,0,.2,1)` |
| A6 | Тики уверенности заливаются по очереди, полоса растёт до 92 % | С A3 карточки, задержка 200 мс | тик 200 мс (шаг 30); полоса 900 мс | ease-out; полоса `(.4,0,.2,1)` |
| A7 | ФСП: маркер «с ФСП» едет от «топ-45 %» к «топ-30 %», заливка следом | Видно 15 % карточки, один раз, задержка 300 мс | 900 мс | `cubic-bezier(.4,0,.2,1)` |
| A8 | Счётчики досчитывают от 0, числа с неразрывным пробелом | Видно 40 % счётчика, один раз | 1400 мс | easeOutCubic |
| A9 | Hover и фокус: карточки +4 px с тенью, кнопки +1 px, стрелка на 3 px; фокус — обводка 2 px с отступом 2 px | Наведение, клавиатура | карточки 180 мс; кнопки 150 мс | ease-out |
| A10 | Смена темы: фон и текст плавно | Клик по иконке в шапке | 200 мс | ease |

**`prefers-reduced-motion`:** A1–A3, A5–A8, пульс и плавная прокрутка отключены; всё сразу в итоговом состоянии, якоря прокручиваются мгновенно.

**Тема и доступность:** по умолчанию системная тема, выбор запоминается (в приложении — общий `ThemeProvider`, E39-2); блок ФСП тёмный в обеих темах; цифры помечены «демо»; контраст AA; вкладки управляются стрелками.

**Заголовок hero** выбран «Тест вместо резюме. Компании приходят сами» (обоснование — spec.html).
