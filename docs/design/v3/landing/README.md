# Лендинг v3

Макет из Claude Design (этап 3, промпт — [prompt-landing.md](../../claude-design/prompt-landing.md)). Реализует задача **E39-35**.

**Файл:** [landing.html](landing.html) — самостоятельная адаптивная страница (1440 → 375 px, перелом на 860 px), светлая и тёмная темы, анимации в одном inline-скрипте. Открыть в браузере напрямую. Холст: https://claude.ai/artifact/J2k6kkprKsA2ruwY74YJES

## Анимации (из макета)

- прилёт карточек hero: `opacity .5s`, `transform .8s cubic-bezier(.16,1,.3,1)`, задержки по `data-fd`;
- появление блоков при прокрутке (`.l-rv`): IntersectionObserver, порог 0.15, `opacity/transform .6s cubic-bezier(.2,.7,.2,1)`, задержки по `data-d`;
- вкладки «Как это работает»: подложка `transform/width .28s cubic-bezier(.4,0,.2,1)`;
- полосы и шкалы: `width .9s cubic-bezier(.4,0,.2,1)`; счётчики досчитывают при появлении;
- hover карточек и кнопок: `transform .15–.18s ease-out` + тень;
- keyframes `l-up`, `l-draw`, `l-pulse`;
- `prefers-reduced-motion: reduce` — всё без анимаций.

## Переходы

«Пройти тест» → `/register?role=candidate` → сразу поток теста (E39-6). «Ищу сотрудников» → `/register?role=employer` → онбординг компании (E39-7). «Войти» → `/login`. Якоря — плавная прокрутка. Других ссылок нет.
