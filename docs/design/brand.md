# Бренд ФСП: токены и правила

> **UI-токены теперь берутся из дизайна:** [handoff/globals.css](handoff/globals.css) (светлая тема в `:root`, тёмная — `.dark`). Там же служебные цвета (успех, предупреждение, ошибка), радиусы 6/8/10/12/20 и тени. Отличие от брендбука: акцентный красный в интерфейсе — `--signal: #D4152D` (темнее брендового `#EC1D35`, чтобы проходить контраст на белом), фон страницы — `#FAFAFC`, карточки — `#FFFFFF`.
> Ниже — исходный анализ брендбука организаторов (SVG-логотипы, носители, фото стенда). Контрасты посчитаны по WCAG 2.1.

## 4. Семантика (расширение бренда, согласовать)

| Смысл | Цвет | Комментарий |
|---|---|---|
| Доверие / подтверждено | синий 500 (заливка точек) | Главный визуальный код продукта |
| Заявлено, не подтверждено | контур синего 300 / серый | Пустые точки ○ |
| Успех (оффер принят, нанят) | `#16A34A` | В бренде зелёного нет, используем редко |
| Предупреждение ⚠ | `#F59E0B` | Объяснения матчинга, «ниже ожиданий» |
| Ошибка / отказ / «🔥 активно ищу» | красный бренда | Красный — «горячий» акцент, как узел в логотипе |

## 5. Типографика

- **JetBrains Mono** (фирменный шрифт из брендбука, на стенде и буклетах). Заголовки, цифры (зарплаты, проценты, счётчики), чипсы навыков, лейблы, код, лог этапов.
- **Основной текст** — открытый вопрос (O12). Варианты: (A) везде JetBrains Mono: сильный «ИТ»-характер, но плотные таблицы работодателя читаются хуже; (B) Mono для акцентов + гротеск с хорошей кириллицей (Onest, Inter, Manrope) для длинных текстов и таблиц. **Рекомендация: B**, а Mono оставить для всего, что «данные».
- Шкала (ориентир): 12 / 14 / 16 / 20 / 24 / 32 / 48 / 64. Заголовки Mono 500–700, межбуквенный 0 / −1%.
- Подключение: `@fontsource/jetbrains-mono` (400, 500, 700), кириллица включена.

## 7. Логотип

- На светлом фоне — версии `*w.svg` (тёмный текст `#1B1C21`). На тёмном — без `w` (светлый текст `#EDEDED`).
- Название продукта ставится рядом со знаком ФСП через вертикальный разделитель: `[знак ФСП] | <Название платформы>`. Не перекрашивать знак, не менять пропорции.
- Минимальный отступ вокруг знака — высота одного узла.
