Граф доказательств

<EvidenceGraph selected />

Кандидат в центре, вокруг навыки, снаружи факты. Размер и заливка узла — доверие, толщина линии — сила факта. Выбор требования вакансии подсвечивает путь «требование → навык → факт», остальное гаснет. Попробуйте кнопки над графом.

Режимы

Обзор — все связи, толщина показывает силу. Путь — выбранное требование вакансии, остальное гаснет до 14%. Развёрнуто — раскрывается на карточке кандидата.

Для скринридера граф дублируется списком «навык — доверие — источники»; без мыши работает через Tab по кнопкам требований.

Поведение

Наведение на узел — поповер «Откуда навык». Клик по пункту совпадения запускает режим пути. Узлы не перемещаются пользователем: раскладка детерминирована, чтобы граф читался одинаково при каждом открытии.

Скелетоны и лоадер-созвездие

Skeleton · ConstellationLoader

Скелетон повторяет форму карточки и пульсирует без градиентов. Для ожидания дольше 3 секунд — лоадер: узлы знака загораются по очереди, а рядом идёт лог сборки.

Собираю граф доказательств…
Когда что

Скелетон — до 3 с, формы известны: список, карточка, профиль.

Лоадер-созвездие — дольше 3 с, есть этапы: сборка профиля, разбор резюме.

Лог сборки — рядом с лоадером, когда этапы можно назвать.

При «уменьшить движение» анимации отключаются, узлы горят все сразу.

Текст 4.5:1, крупный 3:1. Фокус-кольцо 2 px синим с отступом 2 px на всех интерактивных.

Уровень доверия — всегда и точками, и словом в aria-label. Статусы — иконка плюс слово.

Цель нажатия от 44 px на мобильном. Анимации выключаются по prefers-reduced-motion.

Светлая тема по умолчанию; тёмная — hero, карточка кандидата и по выбору.
