# Правила дизайна

## Бренд
- Основной цвет `#402FFF`, глубокий `#201880`, светлый акцент `#A9A1FF`. Подложки `#F4F3FF`, `#E6E4FF`, `#CDC9FF`.
- Красный `#D4152D` («горячая точка»): не больше одного на экран. Знак, метка «новый», текущий шаг, критичное внимание.
- Тонкие границы `#E1E1E5`. Фон страницы `#FAFAFC`. Основной текст `#1B1C21`, вторичный `#5B5D66` или `#4B4D55`.
- Жёлтый и зелёный вне бренда, только для статусов. Предупреждение: фон `#FFF7E6`, граница `#F5D28A`, текст `#5C3A00`. Ошибка: `#FDECEE` и `#B91C2D`. Успех: `#ECFDF3` и `#15803D`.
- Тёмная тема: фон `#1B1C21`, карточки `#22232A`, граница `#34353D`, текст `#EDEDED`, акцентный текст `#A9A1FF`, чипы `#201880`.

## Типографика
- Onest 400/500/600 для текста. JetBrains Mono 400–700 для заголовков, чисел, вилок, меток (метки капсом, 11 px, разрядка .06em).
- Вилка в оффере: JetBrains Mono 700, 30 px, самый крупный элемент карточки.

## Доверие и графика
- Точки доверия: 4 точки. Заполненная `#402FFF`, пустая с контуром `#A9A1FF`. Пунктир означает «предположительно».
- Чипы навыков: подтверждён (сплошной), заявлен (пунктир), предположительно (пунктир), смежный (бледный), «новый» (метка `#D4152D`).
- Грейд: сплошной бейдж, пунктирный если предварительный.
- Кольцо совпадения: `conic-gradient` с переменной `--p`.
- Медали: 1 синяя, 2 `#A9A1FF`, 3 `#E6E4FF` с границей.
- Схемная линия (шаги, трасса): красный узел текущий, пунктир будущие.

## Доступность
- Цели касания на телефоне не меньше 44 px.
- `aria-label` на точках доверия, иконках, кольцах.
- Статусы: иконка плюс слово, не только цвет.
- Фокус: `outline: 2px solid #402FFF; outline-offset: 2px`.
- `prefers-reduced-motion`: показывать итоговый кадр анимаций.

## Принципы продукта
- Профиль кандидата анонимный: «Backend #1307», аватар-созвездие. Контакты уходят только после «Принять».
- Оффер без вилки отправить нельзя. Кандидат видит вилку первой.
- Отказ в один тап по причине, без анкет.
- Подсказки советуют, а не запрещают.
