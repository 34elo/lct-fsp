## 1. Что проектируем

Платформу ФСП, где ИТ-специалиста оценивают по **подтверждённым навыкам** (соревнования ФСП, код, тесты), а работодатель **сам приходит** к кандидату с вакансией и вилкой. Слоган: **«Не резюме, а доказательства»**.

**Название: «ФСП Карьера»** (выбрано 2026-10-01). Варианты, которые рассматривали:
| Вариант | Плюс | Минус |
|---|---|---|
| **ФСП Карьера** | Понятно, официально, сразу связь с федерацией | Скучно |
| **Разряд** | Спортивный разряд + «электрический разряд»; «твой ИТ-разряд» | Можно спутать со спортивными разрядами ФСП |
| **Пруф** | Буквально «доказательство», сленг ИТ | Англицизм |
| **Зачёт** | Спортивное и учебное «засчитано» («Мои победы засчитаны!») | Ассоциация с сессией |

## 2. Тон и характер

- **«Спортивный протокол × IDE».** Строгость результатов соревнований (места, разряды, протоколы) и эстетика среды разработки (моноширинный шрифт, лог сборки, подсветка, схемные линии).
- **Доверие через прозрачность:** у каждой цифры есть источник, у каждого вывода — «почему».
- **Энергия, не пастель:** насыщенный синий бренда, белое поле, тонкие линии, красный — только как «горячая» точка.
- **Анти-паттерны:** стоковые фото людей в офисе, HR-пастель, градиенты «как у всех стартапов», эмодзи вместо иконок в вебе (в Telegram эмодзи уместны).

## 3. Фирменные элементы продукта (signature)

| Элемент | Описание | Где |
|---|---|---|
| **Точки доверия** `○○○○ → ●●●●` | Главный визуальный код. 4 точки, заполненные синим. Пустые — контур. Пересекается с узлами знака ФСП. Ховер или тап открывает поповер «откуда навык»: источники с датами и силой | Везде, где навык |
| **Чип навыка** | `[● ● ● ○] FastAPI` моноширинным шрифтом. Заявленный (только резюме) — пунктирный контур | Профиль, карточки, вакансии |
| **Схемная линия** | Тонкая линия со скруглёнными поворотами и точками на концах (из брендбука). Соединяет блоки, рисует путь | Онбординг, навигатор, лендинг, пустые состояния |
| **Аватар-созвездие** | Генеративный аватар из 5–8 узлов и линий в стиле логотипа, по `seed` псевдонима. Кандидат анонимен, но узнаваем | Анонимные карточки |
| **Лог сборки** | Долгие операции выглядят как терминальный лог: `✓ извлёк текст (2 стр.)`, `✓ нашёл 14 навыков`, `◌ сверяю со справочником…` | Разбор резюме, анализ GitHub, импорт ФСП |
| **Протокол достижения** | Карточка достижения ФСП как строка спортивного протокола: дисциплина, уровень, этап, место / из N, роль (капитан), год | Профиль, карточка кандидата |
| **Рамка-паспарту** | Тонкая синяя обводка с внутренним отступом, как в буклетах ФСП | Hero, ключевые карточки |
| **Цифры моноширинным** | Зарплаты, проценты, счётчики — крупно, JetBrains Mono | Офферы, карта рынка, совпадение |
| **Граф доказательств** | Интерактивный граф на карточке: кандидат в центре, навыки-узлы (размер и заливка по уровню доверия), к ним тянутся линии от фактов (результат ФСП, репозиторий, тест). Выведенные по иерархии навыки — пунктиром, смежные «призрачные» навыки — бледным контуром. Под вакансию подсвечиваются пути «требование → навык → факт» | Профиль, карточка кандидата |
| **Uplift-карточка** | «Подтверди Docker — подойдёшь под **+64%** вакансий (14 → 23)». Крупная цифра моноширинным, способы подтверждения (тест, GitHub, соревнование ФСП с датой) | Профиль, навигатор, бот |
| **Командные сигналы** | Не точки, а слова и факты: «**Лидерство** — сильное подтверждение · капитан на 2 соревнованиях». Отдельно серым — «Указано в резюме: коммуникабельный…» | Профиль, карточка |
| **Новый навык** | Маленькая метка «новый» у навыков, которые только что появились в графе | Навыки |

## 4. Экраны

### 4.1. Лендинг `/`
1. **Hero:** «Не резюме, а доказательства». Подзаголовок: «Платформа ФСП, где навыки подтверждают соревнования, код и тесты, а работодатель приходит сам — с вакансией и зарплатой». Две кнопки: **«Я ищу работу»** (ведёт в Telegram-бот или на регистрацию) и **«Я ищу людей»**. Справа — живая сборка карточки кандидата: резюме → ФСП → GitHub, точки доверия загораются по очереди, соединены схемной линией.
2. **«Как это работает»** — три шага на схемной линии: доказательства → категория → оффер с вилкой.
3. **Счётчики** (моноширинные, крупно): кандидатов, с подтверждением ФСП, компаний, офферов с вилкой.
4. **Карта России** в синем: «таланты из 89 регионов», точки активности.
5. **Для работодателя:** пример карточки с объяснением «92% · ✓ ✓ ⚠» и тепловой картой рынка.
6. **Для ФСП:** «соревнования, которые ведут к карьере» — цикл «соревнование → навык → оффер → новое соревнование».
7. **Сравнение** с универсальными площадками (короткая таблица ✓/—).
8. Футер с логотипом ФСП и партнёрами.

### 4.4. Админ ФСП
- **Дашборд:** воронка «участники ФСП → профили → офферы → наймы», востребованные навыки, карта регионов, переходы из навигатора на соревнования.
- **Справочник и правила:** таблица навыков с алиасами, матрица «дисциплина → навыки» с весами (тепловая), очередь неизвестных навыков.
- **Модерация:** компании, жалобы.
- **Качество алгоритмов:** столбцы «поиск по ключевым словам vs наш подбор». Главная цифра: «доля приукрашенных резюме в топ-10: 31% → 6%». Вклад каждого источника (ФСП, код, тесты).

## 5. Вау-моменты (для демо и жюри)

1. **Точки загораются** после «Войти через ФСП»: волна заполнения + перещёлкивание грейда + короткий звук или вибрация (опционально).
2. **Лог сборки** при разборе резюме: терминал в фирменном стиле, строки печатаются по мере прихода этапов (реальные SSE-события).
3. **Текст → чипсы** в поиске работодателя.
4. **Кольцо совпадения** с объяснением, где каждый пункт подсвечивает доказательство в карточке.
5. **Навигатор-трасса** с соревнованиями ФСП как контрольными точками.
6. **Живое обновление:** на экране работодателя или кандидата профиль меняется сам, когда админ публикует результат ФСП.
7. **Аватары-созвездия** вместо фото: анонимно и в стиле бренда.
8. **Карта России** с регионами на лендинге и в дашборде.
9. **Страница качества:** продукт измеряет сам себя.
10. **Граф доказательств** на карточке: пути подсвечиваются при наведении на ✓ в объяснении.
11. **Uplift «+64% вакансий»** с одной кнопкой «Пройти тест».
12. **Рост графа навыков** в админке: новые вершины появляются и прорастают связями (анимация за неделю).

## 6. Состояния

- **Пусто:** схемная линия ведёт к действию («Подключи ФСП, чтобы навыки загорелись»).
- **Загрузка:** лоадер-созвездие (узлы знака загораются по очереди), скелетоны в форме карточек.
- **Предварительно:** грейд с пунктирной обводкой и подсказкой «добавь GitHub или пройди тест, чтобы уточнить».
- **Ошибка:** спокойный тон, что случилось и что сделать. Без красных экранов на всю ширину.
- **Не верифицировано:** достижение ФСП с пометкой «не подтверждено» и кнопкой «подтвердить».

## 9. Требования

- Адаптив: кандидат — от 360 px, работодатель — от 1280 px (не ломаться на 768).
- Светлая тема по умолчанию (как носители ФСП). Тёмная тема — для hero и как опция (как стенд ФСП). В тёмной теме синий бренда не используем для мелкого текста ([brand.md §3](brand.md#3-контраст-важно)).
- Доступность: контраст AA, фокус-кольца, точки доверия дублируются текстом для скринридеров («уровень доверия 3 из 4»), не только цветом.
- Иконки: линейные, 1.5 px (Lucide), в тон тонким схемным линиям.
- Компоненты строятся на shadcn/ui (Radix), макеты должны ложиться на них.

3. Кандидат (мобильный): профиль, офферы, онбординг с логом сборки, навигатор.
4. Лендинг (hero + 3 блока).
5. Админ: дашборд и страница качества.
6. Публичный профиль, бейдж, Telegram-сообщение об оффере.
