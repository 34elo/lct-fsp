# Промпт для Claude Design

## Как отправлять

1. **Первое сообщение:** приложи архив брендбука и вставь «Основной промпт». Если архив `.rar` не принимается, распакуй его и приложи файлы по отдельности или одним `.zip`: `logo_01w.svg`, `logo_01.svg`, `logo_02w.svg`, `lineline1.png`, `map1.png`, `face1.png`, `example.png`, `photo.jpeg`. Они же лежат в `docs/design/assets/`.
2. **Дальше** — уточняющие промпты по порядку, каждый отдельным сообщением и только после того, как предыдущий результат устроил. Правки пиши коротко: «точки доверия крупнее», «вилку сделать главным элементом».
3. **В конце** — промпт «Передача в разработку». Результат (ссылки на макеты, токены, код компонентов) отдай фронтендеру и впиши ссылки в [brief.md](brief.md).

## Основной промпт

```text
Спроектируй веб-платформу «ФСП Карьера» для Федерации спортивного программирования России (ФСП). Интерфейс на русском языке. К сообщению приложен брендбук ФСП — следуй ему.

## Что это за продукт
Отраслевой ИТ-агрегатор с обратной механикой найма. Кандидат не откликается на вакансии. Система строит его профиль как «граф доказательств»: проверяемые факты (результаты соревнований ФСП, код на GitHub, адаптивные тесты, ИИ-интервью по собственному коду) подтверждают навыки с разной силой. Из этого автоматически получаются уровни доверия к навыкам, категория (роль × грейд × стек) и грейд с объяснением «почему». Работодатель ищет среди анонимных проверенных профилей, видит, почему человек подходит, и сам присылает оффер с обязательной зарплатной вилкой. Кандидат получает оффер в Telegram и отвечает одной кнопкой; контакты раскрываются только после «да». Кандидат также видит, какой навык подтвердить, чтобы подходить под N% больше вакансий, и на каком соревновании ФСП это можно сделать.
Слоган: «Не резюме, а доказательства».

  Шкала синего: 50 #F4F3FF, 100 #E6E4FF, 200 #CDC9FF, 300 #A9A1FF, 400 #796DFF, 500 #402FFF, 600 #3628D9, 700 #2C20AD, 800 #201880, 900 #140F52.
  Вне бренда, редко: успех #16A34A, предупреждение #F59E0B.
- Шрифты: JetBrains Mono (фирменный) — заголовки, все цифры (зарплаты, проценты, счётчики), чипсы навыков, лейблы, код. Onest — длинный текст и таблицы.
- Графический язык ФСП: тонкие «схемные» линии с плавными скруглёнными поворотами и точками на концах; знак-созвездие из узлов и линий; тонкая синяя рамка-паспарту на белом поле; карта России в сплошном синем; каркасная 3D-голова — только для ИИ-функций.
- Светлая тема по умолчанию. Тёмная (#1B1C21) — для hero и как опция; в тёмной теме #402FFF только для заливок, для текста — #A9A1FF.
- Характер: «спортивный протокол × IDE». Строго, технично, энергично. Без стоковых фото, HR-пастели и модных градиентов. Иконки линейные 1.5 px (Lucide). Скругления 6–10 px, тени минимальные, разделение тонкими линиями 1 px, сетка 8 px.

## Фирменные компоненты (сначала — отдельная страница дизайн-системы)
1. Точки доверия: 4 точки (○○○○ … ●●●●), заполненная — синий 500, пустая — контур синего 300. Поповер «Откуда навык»: источники с иконкой, датой и силой.
2. Чип навыка: [●●●○ FastAPI] моноширинным; «заявлено» — пунктирный контур; «новый навык» — маленькая метка «новый»; «выведено из FastAPI» — пунктирные точки.
3. Аватар-созвездие: генеративный аватар из 5–8 узлов в стиле знака ФСП вместо фото (кандидаты анонимны).
4. Кольцо совпадения «92%» + пункты ✓ (синий) / ⚠ (жёлтый) / ✗; каждый пункт кликабелен.
5. Шкала «Вероятность принятия» (низкая / средняя / высокая) — интерес кандидата к офферу.
6. Строка протокола ФСП: дисциплина · уровень · этап · место из N · роль (капитан) · год, медаль для 1–3 места.
7. Бейдж грейда «Middle · Backend · Python» и вариант «предварительно» (пунктир).
8. Командные сигналы: без точек, словами и с фактами — «Лидерство — сильное подтверждение · капитан на 2 соревнованиях»; отдельно серым «Указано в резюме: коммуникабельный».
9. Граф доказательств: интерактивный граф — кандидат в центре, навыки-узлы (размер и заливка по доверию), узлы-факты, линии с силой; выведенные навыки пунктиром, смежные — бледным контуром; режим подсветки пути «требование вакансии → навык → факт».
10. Uplift-карточка: «Подтверди Docker — подойдёшь под +64% вакансий (14 → 23)», крупная цифра, способы подтверждения (тест 10 мин · GitHub · соревнование ФСП 15 ноября), кнопка «Пройти тест».
11. Лог сборки: терминальный блок для долгих операций («✓ Извлёк текст (2 стр.)», «◌ Сверяю навыки со справочником…»).
12. Схемная линия как соединитель и путь (горизонтальная и вертикальная, узлы-шаги).
13. Карточка оффера: вилка «200 000 – 250 000 ₽» — самый крупный элемент; компания с рейтингом ответственности; роль; формат; совпадение; срок ответа; кнопки «Принять», «Не подходит», «Задать вопрос».
14. Бейджи статусов оффера: отправлен, просмотрен, принят, отклонён (с причиной), истёк, интервью, нанят.
15. Кнопки обратной связи на карточке кандидата «В шорт-лист» / «Не подходит» и чипсы над выдачей «Учли: чаще выбираете кандидатов с ФСП ×».
Плюс базовые: кнопки (primary синяя, secondary контурная, ghost), поля, селекты, слайдер диапазона зарплаты, табы, чипсы фильтров с крестиком, тосты, модалки, нижние листы (мобильный), скелетоны, лоадер-созвездие (узлы знака загораются по очереди).
```

