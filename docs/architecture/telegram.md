# Telegram-бот

> Канал кандидата: **бот + адаптивный сайт**. Mini App — в дорожной карте. Всё, что неудобно делать кнопками (правка профиля, навигатор целиком), бот открывает на сайте по **одноразовой ссылке со входом**.

## 1. Архитектура

- `services/bot`, **aiogram 3**, **long polling** (домашнему серверу не нужен входящий HTTPS; webhook можно включить позже через edge).
- FSM-хранилище — `RedisStorage` (`fsm:*`).
- **Без бизнес-логики:** каждое действие вызывает `core-api /internal/tg/*` с сервисным токеном и `tg_user_id`.
- **Исходящие** сообщения читает из очереди RabbitMQ `bot.telegram` (команды `notify.telegram`, FastStream, подтверждение после отправки). Шаблоны и клавиатуры рендерит сам бот (`bot/templates/*.py`, HTML-разметка Telegram).
- **Лимиты Telegram:** до ~30 сообщений/с на бота и ~1 сообщение/с в один чат. Отправитель — token bucket 25/с глобально + 1/с на чат, ретраи по `RetryAfter`.
- Один бот на всех. Роль определяется по привязанному аккаунту: работодатель получает только уведомления (C).

## 2. Команды и меню

| Команда / кнопка меню | Что происходит |
|---|---|
| `/start [param]` | `param` может быть `link_<token>` (привязка к аккаунту с сайта) или `ref_<source>`. Приветствие → «как это работает» (3 пункта) → согласия |
| 📄 Резюме | «Пришли PDF или DOCX» → файл → «Разбираю…» (одно сообщение, редактируется по этапам) → «Вот что я понял» → [✅ Всё верно] [✏️ Исправить на сайте] |
| 👤 Профиль | Категория, грейд (с «предварительно»), топ-6 навыков со значками, ФСП-достижения → [🌐 Открыть профиль] |
| 🏆 ФСП | Статус привязки → [🔑 Войти через ФСП] (ссылка) / [Ввести ID] → код подтверждения → список достижений |
| 🧬 GitHub | «Пришли ник» → прогресс по репозиториям → радар картинкой (рендер на бэкенде, 🚀) или текстом + новые подтверждённые навыки |
| ✅ Проверить навык | Список навыков с банком вопросов → тест кнопками (F9) |
| 🤖 ИИ-интервью (🚀) | Вопросы по своему коду, ответ текстом или голосом |
| 💼 Офферы | Активные офферы, по каждому кнопки действий |
| 🧭 Навигатор | «До Middle не хватает: Docker (+14 вакансий)…» + ближайшее соревнование ФСП → [Подробнее на сайте] |
| 🔥 Статус | [🔥 Активно ищу 7 дней] [👀 Открыт] [🔕 Не беспокоить] |
| ⚙️ Настройки | Минимальная зарплата, формат → кнопками; остальное — ссылкой на сайт |
| `/delete` | Удаление профиля с подтверждением |

## 3. Состояния FSM

| Состояние | Ждём | Выход |
|---|---|---|
| `onboarding.consents` | нажатие согласия | → `idle` |
| `resume.awaiting_file` | `document` (pdf/docx ≤ 10 МБ) | → `idle` после постановки задачи |
| `fsp.awaiting_id` | текст: ID или email участника | → `fsp.awaiting_code` |
| `fsp.awaiting_code` | 6 цифр | → `idle` |
| `github.awaiting_login` | текст | → `idle` |
| `test.in_progress:{session}` | callback ответа | → `idle` после результата |
| `offer.awaiting_question:{offer_id}` | текст вопроса | → `idle` |
| `interview.answering:{id}:{q}` | текст / voice | → следующий вопрос или `idle` |
| `settings.awaiting_salary` | число | → `idle` |

Таймаут состояний — 30 минут, затем сброс в `idle` с подсказкой.

## 4. callback_data (≤ 64 байт)

См. [api.md §5](api.md#5-сообщения-бота-callback_data). Обработчик проверяет, что `tg_user_id` нажавшего совпадает с владельцем ресурса (это делает core по `tg_user_id`).

## 6. Безопасность

- Сервисный токен бота хранится только в env бота и core.
- Входящие файлы бот не сохраняет у себя: стримит в core.
- Telegram Login Widget на сайте проверяется в core (HMAC с ключом SHA256(bot_token), `auth_date` ≤ 24 ч).
- Сообщения с контактами отправляются только участникам оффера.
