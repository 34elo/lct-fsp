# ФСП Карьера: пакет дизайна для разработки

Макеты платформы «ФСП Карьера» (Федерация спортивного программирования России): 38 экранов, токены, компоненты, логотипы.

Положите папку в репозиторий как `design/` и откройте `index.html`: там галерея всех экранов.

## Что внутри

| Папка | Что это | Зачем |
|---|---|---|
| `screens/png/` | Картинка каждого экрана | Эталон внешнего вида, сверять результат с ним |
| `screens/html/` | Готовая разметка экрана со всеми стилями (статичный снимок) | Брать структуру, размеры, отступы, цвета. Не копировать как есть, а переносить в компоненты |
| `tokens/globals.css` | CSS-переменные светлой и тёмной тем | Подключить в корень приложения |
| `tokens/tailwind.config.ts` | Цвета, шрифты, радиусы | Слить в конфиг Tailwind |
| `components/fsp-ui.tsx` | React + Tailwind: TrustDots, SkillChip, ConstellationAvatar, MatchRing, CandidateCard, OfferCard, UpliftCard | Готовые компоненты, переиспользовать |
| `assets/` | Логотипы ФСП, каркасная голова, карта России | Брать отсюда, не перерисовывать |
| `docs/SCREENS.md` | Таблица экранов: маршрут, размер, поведение, адаптив | План работ |
| `docs/DESIGN_RULES.md` | Правила бренда и доступности | Обязательно к прочтению |
| `docs/BEHAVIOR.md` | Формулы и логика интерактивных мест | Реализовать как написано |
| `docs/DATA.md` | Демо-данные из макетов | Для сторибука и тестов |
| `source/` | Исходники досок в формате дизайн-инструмента (`*.dc.html`) | Только для справки, напрямую не запускать |

## Стек, под который сделан макет

React 18, Tailwind 3.4, shadcn/ui, class-variance-authority. Шрифты: Onest (текст) и JetBrains Mono (заголовки, числа, метки), подключаются с Google Fonts или через `@fontsource`.

## Быстрый старт

1. Скопируйте `tokens/globals.css` в `src/styles/` и импортируйте в корневом layout.
2. Слейте `tokens/tailwind.config.ts` в `tailwind.config.ts`.
3. Скопируйте `components/fsp-ui.tsx` в `src/components/`. Нужна утилита `cn` из shadcn.
4. Подключите шрифты: `npm i @fontsource/onest @fontsource/jetbrains-mono`.
5. Верстайте экраны по `docs/SCREENS.md`, сверяясь с `screens/png`.

## Важно

- Данные в макетах выдуманы (кандидаты #4821 и другие, компании «Северный код», «Полярные системы», все метрики). Маршруты в `SCREENS.md` предложены, не согласованы.
- Макеты не проходили проверку в браузерах кроме Chromium. Код компонентов проверен на синтаксис и в Tailwind не собирался.
- Интерактив в `screens/html` не работает: это снимок. Логика описана в `docs/BEHAVIOR.md`.
