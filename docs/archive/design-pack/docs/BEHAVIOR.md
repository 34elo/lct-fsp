# Поведение и формулы

## Оффер (экран C)
- Медиана категории Middle · Backend: 275 000 ₽. Ожидания кандидата в демо: 230 000 ₽.
- Поля «от» и «до»: только цифры, отображение с пробелами по разрядам.
- Ошибка, если одна граница пуста или «до» < «от». Кнопка «Отправить оффер» приглушается (opacity .45).
- Подсказки: ниже или выше медианы на N% = `round((середина / 275000 − 1) · 100)`. Нижняя граница против ожиданий кандидата. «Слишком широкая вилка», если `(до − от) / от > 0.5`.
- Вероятность принятия: `score = (0.4·от + 0.6·до) / ожидания − (широкая ? 0.08 : 0)`. Уровень 1 при score < 0.9, 2 при < 1.08, иначе 3 (низкая, средняя, высокая).

## Редактор вакансии (E3)
- Требуемые навыки с уровнями 0–4 (точки-кнопки).
- Превью: `кандидатов = max(2, 59 − 4·сумма уровней)`, `с ФСП = round(кандидатов · 0.39)`.
- Предупреждение «Слишком широкая вилка» при `до / от > 1.6`.

## Подборка (E4)
- Сортировка «по интересу»: `0.6·совпадение + 0.4·вероятность`. «По совпадению»: только совпадение.
- Обоснование открыто у топ‑5, у остальных раскрывается.

## Рынок (E1)
- Матрица 9 ролей × 6 грейдов, сумма 412. Шкала цвета из 5 ступеней по min/max выбранной метрики. Пустая ячейка «—».
- Клик по ячейке ведёт в поиск с фильтрами роли и грейда.

## Граф (G1, G2)
- G1: наведение или фокус на факте подсвечивает его рёбра и связанные навыки, остальное opacity .14.
- Рёбра к навыку с «предположительно» пунктирные. Смежный навык бледный.
- G2: тап по узлу открывает нижний лист: название, уровень, статус, два доказательства, кнопка «Подтвердить навык».

## Рост (M3)
- Навигатор: Docker +64%, Kafka +29%, вместе +93%. «До Middle не хватает 1.5 балла: тест по Python (+1–2)».
- Адаптивный тест: таймер 60 с (кольцо), «Вопрос N · уровень уточняется». Результат: Python ●●○○ → ●●●○, действует до октября 2027.

## Модерация и пульт (F3, F4)
- F3: кнопки «Подтвердить / Отклонить / Вернуть» меняют статус карточки и счётчики.
- F4: каждая кнопка добавляет строку в журнал (последние 8).

## Админка навыков (G3)
- Ползунок «Коэффициент смежности» 0–1. Влияет на вес смежного навыка и показывает оценку охвата. Сохранение сопровождается пересчётом на копии данных.

## Анимация E2
- Кадр 1: печать по символам (18 мс). Кадр 2: подсветка слов (80 мс). Кадр 3: слова уходят по линии в чипсы (240 мс). Цикл 9 с. При `prefers-reduced-motion`: сразу кадр 3.
