## 7. Технический старт (Д0–Д1)

**Цель дня 0–1 — «ходячий скелет»:** всё поднимается одной командой, сквозной путь работает на заглушках.

| Шаг | Кто | Результат |
|---|---|---|
| Монорепо из [workflow.md](../process/workflow.md): uv workspace, `packages/contracts`, `packages/platform`, шаблон сервиса | B1 | `make lint test` зелёный |
| Compose: postgres, rabbitmq, redis, minio, gateway + пустые сервисы с `/healthz` | B1 | `make up` на сервере, домен открывается |
| Контракты v1 (события, команды, DTO) — ревью трёх сторон | B1 + ML + B2 | PR в `packages/contracts` |
| `bench_llm.py`: 3 модели × скорость и качество на 5–15 резюме | ML | Выбрана модель (запись в notes) |
| ML-заглушки (`ML_FAKE=true`) для всех задач ml | ML | Фронт и бэк не ждут GPU |
| Каркас web: роутер, layout'ы, токены ФСП, клиент из OpenAPI | FE | Пустые экраны в фирменной теме |
| Каркас fsp-mock + бот, отвечающий на `/start` | B2 | Бот живой |
| **Скелет сквозного пути на заглушках:** загрузка резюме → фейковый разбор → доказательства → профиль с точками → оффер → push в бот | все | Видео 30 с в чат команды |

### Как работать локально

| Роль | Что поднимать | Команда (появится с кодом) |
|---|---|---|
| Фронтенд | core + заглушки ML, без GPU | `make dev-core` (`ML_FAKE=true`) + `pnpm dev` |
| Бэкенд | core + rabbitmq + postgres + redis, ML-заглушки | `make dev-core` |
| ML | ml-api + ml-worker + llm-chat на сервере или локально на CPU-профиле | `make dev-ml` (`LLM_PROFILE=cpu` на ноутбуке) |
| Бот | core + bot с отдельным тестовым ботом (свой токен у каждого разработчика) | `make dev-bot` |

- **Тестовые данные локально:** `make seed SEED=42` (маленький размер, `SEED_SIZE=small`).
- **Тесты:** юнит-тесты формул (доверие, грейд, `K_soft`, uplift, `p_accept`) — обязательно с первого дня. Интеграционные — testcontainers (PostgreSQL, RabbitMQ, Redis). Контрактные — схемы `packages/contracts`. Сквозной — Playwright на демо-сценарий с Д6.
