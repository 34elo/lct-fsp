# Бэклог (черновик для постановки задач)

> Источник задач для трекера. Роли: **B1** — бэкенд (ядро), **B2** — бэкенд (интеграции: офферы, бот, ФСП), **FE** — фронтенд, **ML**, **PM**. В команде из 4 человек задачи B2 делят B1 и FE (бот на aiogram простой).
> Приоритет: M / S / C (MoSCoW). **Д** — день хакатона, к концу которого задача должна быть готова.

## Вехи

| Веха | К концу | Критерий |
|---|---|---|
| **M0** Каркас | Д1 | Compose поднимается на сервере, домен с TLS открывается, LLM замерена и выбрана, контракты v1 согласованы, черновик справочника |
| **M1** Кандидат | Д3 | Резюме → разбор → ФСП (мок) → профиль с доверием, категорией и грейдом на сайте |
| **M2** Сквозной путь | Д5 | Работодатель → вакансия → подборка/поиск → карточка → оффер → push в Telegram → принять → контакты. **Работает каждый вечер дальше** |
| **M3** Подтверждение | Д7 | ДНК кода, адаптивный тест (сайт + бот), поиск текстом, карта рынка, навигатор |
| **M4** Вау и качество | Д9 | Вау-фичи по ресурсам, страница качества с метриками, полировка по брендбуку, документация |
| **M5** Фриз | Д10 | Репетиции, видео демо, питч |
