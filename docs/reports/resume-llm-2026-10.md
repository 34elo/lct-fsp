## 2. Сравнение вариантов на эталонах

Эталонов в `data/eval/resumes/` десять (набор hh.ru, `gold.json`), а не пятнадцать. Реальная Qwen3-VL-4B без чтения `.env` недоступна (адрес и ключ только там), поэтому прогон на модели не выполнен. Сделан готовый скрипт `tools/eval/resume_llm_variants.py`. Он проверен на фейковом клиенте, часть ответов которого пустая.

Варианты: `base` (temperature 0.1, max_tokens 4096, без рассуждений), `t0`, `t03` (температура 0 и 0.3), `max8k` (max_tokens 8192), `think` (рассуждения включены, 8192), `sections` (текст кусками по ~2500 знаков, навыки сливаются), `simple` (схема только из навыков), `fewshot` (пример в промпте).

Команда для стенда:

```
LLM_BASE_URL=... LLM_API_KEY=... LLM_MODEL=qwen3-vl-4b \
  PYTHONUTF8=1 uv run python tools/eval/resume_llm_variants.py --json reports/resume-llm.json
```

Что измерено без LLM (правиловый разбор `extract_rules` + `assemble`, 10 резюме hh): полнота навыков по эталону 1.00, среднее время 0.009 с на резюме, нулевых ответов нет. Колонки LLM заполняются прогоном на стенде.

## 3. Запасной путь (сделано)

`resume_parser.parse_resume`: после проверки цитат, если навыков 0 (при непустом тексте) или меньше 3 при тексте длиннее 1000 знаков, вызывается `merge_rules_fallback`. Навыки правилового `extract_rules` проходят ту же `assemble` (цитата найдена в тексте, навык упомянут в цитате), добавляются только новые по `slug`, помечаются `source: "rules"`, в `warnings` появляется `llm_fallback_rules:<n>`. Навыки LLM, опыт, образование и контакты не меняются. Контракт: `ResumeSkill.source: "llm" | "rules" = "llm"` (совместимое добавление, `docs/openapi.json`, `docs/asyncapi.json`, `apps/web/openapi.json` и модель `resumeSkill.ts` обновлены; при ближайшем `pnpm api:gen` модель перегенерируется). Тесты: `services/ml/tests/test_resume_parser.py` (нулевой ответ, мало навыков при длинном тексте, отсутствие запасного пути при достаточном числе навыков или коротком тексте, пороги).

## 4. Логирование (сделано)

Запись `resume_parsed` теперь содержит `prompt_version`, `parser_version`, `chars`, `llm_skills` (до проверки цитат), `skills`, `unknown`, `experience`, `education`, `dropped`, `dropped_share`, `fallback_rules`, `declared_dropped`, `seconds`. Нулевой ответ LLM — предупреждение `resume_llm_empty_skills`. ПДн (текст, имена, цитаты) в лог не попадают.
