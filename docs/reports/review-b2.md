## Прочее, замеченное попутно

- `/jobs/:id` ищет вакансию в первых 100 публичных (отдельного `GET /vacancies/public/{id}` нет). Список `/jobs` тоже ограничен 100, поэтому сейчас всё открываемое находится; при росте числа вакансий нужен эндпоинт одной вакансии.
- Повторный запрос страницы категории с тем же `session_id` (обновление страницы) снова пишет показы — дубли в `impressions` для метрик по позициям (так же устроен обычный поиск).
- Заявка **З-2-02** всё ещё открыта (`invite_task_*` в `assessment/service.py` нет): `POST /offers` с `task` отвечает 503. Напарник больше не кодит, поэтому её нужно взять отдельной задачей.
- `tools/tests/test_eval_llm.py::test_env_file_reads_only_llm_keys` падает на Windows с `UnicodeDecodeError` (кириллица в пути профиля) — та же природа, что у известных падений `tools/test_new_service`; задача E32-3, не из этого списка.
- Тексты уведомления «новый результат ФСП» при full-синке (все результаты заново, `count > 0`) всё равно говорят «новый» — коннектор не различает новые и уже импортированные; правка в коннекторе, отдельной задачей.
