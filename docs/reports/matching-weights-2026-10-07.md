# Настройка весов подбора 2026-10-07 (E36-6)

> **Синтетика.** Пары «потребность – кандидат» и их релевантность — синтетический рынок `tools/synth` (истина по скрытым уровням навыков). **Ручной разметки 30 потребностей в репозитории нет** (`data/gold/relevance.jsonl` не собран, evaluation.md §2), поэтому настройка сделана только на синтетике. Персональных данных нет.

- Ветка `block2`, дата прогона: 2026-10-07, прогон около 1,5 минуты.
- Воспроизведение: `uv run python tools/eval/tune.py --out reports/eval-tune` → `reports/eval-tune/tune.{md,json}`. Результат детерминирован (seed'ы рынков из `tools/synth/config.yaml`).
- Против переобучения: веса выбираются только на train (рынок `dev`, seed 1001); «после» и решение — на holdout (рынок `test`, seed 2002, тот же, что считает `make eval`). Веса принимаются, только если на holdout выросли и P@10, и nDCG@10 в обоих режимах.
- Что подбиралось: `matching_weights` (skills / grade / salary / fsp, шаг 0.05, каждый ≥ 0.05, сумма 0.80; вес семантики 0.20 фиксирован — эмбеддингов в синтетике нет), `skills_coverage.required_weight_multiplier` (2 / 3 / 4), `strength.rank_match` (0.3…1.0, `rank_strength = 1 − rank_match`). Критерий на train — среднее nDCG@10 режимов match и rank.

**Вывод.** Ландшафт плоский: лучшие на train веса отличаются от прежних на тысячные доли, а на holdout в режиме match nDCG@10 даже снизился (−0.001 при 95 % интервале ±0.006). Критерий принятия не выполнен — **веса в `scoring.yaml` не менялись** (добавлен комментарий с результатом). Подбор по-прежнему впереди BM25 (+130 % nDCG@10) и BM25 с фильтрами (+4.8 %). Резерв роста — не в весах компонентов, а в модели уверенности навыков, фильтрах и семантике (её вклад на синтетике не измерить).

Train — синтетический рынок `dev` (seed 1001, 1000 кандидатов, 110 потребностей); holdout — рынок `test` (seed 2002, 1000 кандидатов, 109 потребностей), хеш параметров `b6c60b163a9f`. Веса выбраны только по train; решение принять их — по holdout (растут P@10 и nDCG@10 в обоих режимах).

## Итог на holdout

- match: P@10 +0.001 (+0.3 %), nDCG@10 -0.001 (-0.2 %); 95 % интервал разницы nDCG@10 по потребностям ±0.006.
- rank: P@10 +0.005 (+1.5 %), nDCG@10 +0.002 (+0.6 %); 95 % интервал разницы nDCG@10 по потребностям ±0.008.
- Против BM25 с фильтрами (match): до — nDCG@10 +0.019 (+4.8 %), после — +0.018 (+4.6 %).
- Решение: улучшения на holdout нет — веса не меняем.

Ограничения: рынок синтетический; ручной разметки потребностей в репозитории нет (`data/gold/relevance.jsonl` не собран) — настройка только на синтетике. Семантика (эмбеддинги) в синтетике не моделируется, её вес не настраивался. Сила профиля — по заменам: T — доля верных ответов теста, R = 1, C = 1. Разница между соседними узлами сетки мала (тысячные доли), поэтому выбор ограничен узкой сеткой рядом с прежними весами.
