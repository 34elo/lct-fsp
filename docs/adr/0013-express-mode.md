# ADR-0013. Экспресс-режим для жюри

**Статус:** принято · **Область:** Тест

## Контекст

Жюри хочет само пройти тест за 3–5 минут, а не только смотреть демо-аккаунт.

## Решение

Режим `express`: 6–8 заданий, α = β = 0.15, без бонуса и пилотов. Грейд помечается «экспресс»: обычный тест заменяет его без кулдауна, сам экспресс обычный грейд не перекрывает. Песочница жюри создаёт свою пару «кандидат + работодатель» на каждый вход.

## Почему

Механику можно проверить руками за несколько минут.

## Последствия

Точность экспресс-грейда ниже (≈ 70 % вне зоны безразличия) — он помечен и не заменяет основной тест.
