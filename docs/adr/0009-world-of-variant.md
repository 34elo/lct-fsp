# ADR-0009. «Мир» — общий контекст варианта задания

**Статус:** принято · **Область:** Тест

## Контекст

Нужно, чтобы задания одного семейства у разных кандидатов выглядели как разные задачи, но с той же сложностью.

## Решение

`World.from_seed(seed, domain)` детерминированно строит вымышленную компанию: домен, сущности, граф сервисов, связанные таблицы с данными, метрики, команду. Семейства берут из мира имена, числа и артефакты; ручки сложности — из своего генератора.

## Почему

Один механизм закрывает уникальность вариантов и задания по архитектуре, данным и инцидентам.

## Последствия

Порядок генерации мира нельзя менять: от него зависят уже выданные варианты.
