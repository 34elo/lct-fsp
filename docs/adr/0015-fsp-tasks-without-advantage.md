# ADR-0015. Задачи соревнований ФСП в банке без преимущества участников

**Статус:** принято · **Область:** Тест

## Контекст

Организаторы разрешили задачи прошлых соревнований как дополнительные, но просили защитить тех, кто их не решал.

## Решение

Источник `fsp` с `competition_id`. Участнику соревнования его задачи не выдаются. Участие в ФСП не даёт бонуса к θ. Калибровка `b` таких задач — только по ответам кандидатов без ФСП. Допуск в `active` требует измеренного DIF «с ФСП / без ФСП». Без лицензии и происхождения банк не принимается.

## Почему

Задачи ФСП усиливают банк, не превращая платформу в площадку для олимпиадников.

## Последствия

Участники, не привязавшие FSP ID, остаются слепым пятном: их ловят DIF и тревога утечки.
