# ADR-0021. SSE для живых обновлений, бот на long polling

**Статус:** принято · **Область:** Архитектура

## Контекст

Нужны уведомления в реальном времени; стенд за VPS-прокси, входящих вебхуков на сервер команды нет.

## Решение

Поток «сервер → клиент» — SSE `/events/stream` через UI-шину RabbitMQ, действия — обычный REST. Telegram-бот — aiogram long polling; сложные экраны — сайт по одноразовой ссылке.

## Почему

Работает через любые прокси, автоматическое переподключение, не нужен входящий вебхук Telegram.

## Последствия

Telegram Mini App — в дорожной карте.
