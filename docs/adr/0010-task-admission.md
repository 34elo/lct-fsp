# ADR-0010. Допуск заданий: draft → pilot → active через администратора

**Статус:** принято · **Область:** Тест

## Контекст

Задания приходят из генераторов, майнинга, конструктора работодателей и LLM. Непроверенное задание не должно влиять на грейд.

## Решение

Любое новое задание проходит автопроверку и попадает в `pilot`: показывается в скрытых пилотных слотах без влияния на θ. В `active` — только кнопкой администратора при выполнении порогов (n ≥ 30, r_pb ≥ 0.2, |b| ≤ 3, разброс по сидам, DIF «с ФСП / без ФСП», утверждённый ключ). Ключ от LLM — всегда черновик. Тревоги (низкая r_pb, утечка, апелляции) переводят в карантин автоматически.

## Почему

Банк растёт без риска для оценки; работодатели становятся соавторами заданий.

## Последствия

Нужна очередь допуска у администратора и поток кандидатов для пилота.
