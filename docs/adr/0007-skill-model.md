# ADR-0007. Модель навыков: шесть типов, профессии как профили

**Статус:** принято · **Область:** Тест

## Контекст

Профессии меняются (появился AI Engineer); тест должен проверять не только технологии, но и мышление, бизнес, софт.

## Решение

У навыка есть тип: фундамент, хард, мышление, бизнес, софт, опыт — и карточка (утверждения по уровням, понятия, заблуждения). Профессия — взвешенный набор навыков. План теста — доли типов по грейду × веса навыков профессии. Новые профессии предлагает система по кластерам навыков вакансий и запросов, подтверждает администратор.

## Почему

Новая профессия добавляется данными, без кода; шкала грейдов универсальна для всех профессий.

## Последствия

Глубина теста по профессии зависит от покрытия банка заданий её навыков.
