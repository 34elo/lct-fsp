# ADR-0022. Open Badge 3.0 с подписью eddsa-jcs-2022

**Статус:** принято · **Область:** Интеграции

## Контекст

Кандидату полезно унести подтверждённый грейд с платформы в проверяемом виде.

## Решение

Подписанный кредит Open Badge 3.0: Data Integrity `eddsa-jcs-2022` (JCS + Ed25519), издатель `did:web`, публичный ключ в `/.well-known/did.json`, отзыв через `revoked_at`. Выпуск — только для того, что кандидат сам сделал публичным.

## Почему

JCS не требует канонизации RDF и загрузки JSON-LD-контекстов при выпуске.

## Последствия

Сторонний валидатор должен поддерживать `eddsa-jcs-2022`; в кредитах нет чисел с плавающей точкой.
