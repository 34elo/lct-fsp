# ADR-0023. Дизайн-система — пакет @fsp/ui

**Статус:** принято · **Область:** Фронтенд

## Контекст

Несколько разработчиков делают экраны параллельно; нужен единый вид и тёмная тема.

## Решение

Токены, тема Tailwind 4, базовые и фирменные компоненты — в `packages/ui` (без сборки, экспорт исходников). Экраны собираются из пакета, цвета и шрифты только из токенов. pnpm workspace с одним lock-файлом.

## Почему

Единый вид, тёмная тема и контраст проверяются в одном месте; playground для просмотра компонентов.

## Последствия

Новый общий компонент добавляется в пакет, а не в экран.
