# ADR-0018. LLM — сменный модуль, ядро работает без неё

**Статус:** принято · **Область:** ML

## Контекст

На стенде жюри нет GPU; организаторы предпочитают открытые модели, допускают облачные, но риски 152-ФЗ — на команде.

## Решение

Тест, калибровка, категории, подбор и офферы не зависят от LLM. У каждой LLM-функции есть путь без неё (флаг `LLM_ENABLED`). Профили запуска: `lite` (без LLM, эмбеддинги на CPU), демо (заглушки), полный (OpenAI-совместимый сервер). По умолчанию модель локальная (`llama-server`, Qwen3-VL-4B на стенде команды); облачный провайдер — только настройкой `LLM_BASE_URL`, на нашем стенде не используется из-за трансграничной передачи ПДн. Core в LLM ходит только через ml-api и очередь `ml.llm`.

## Почему

Требование ТЗ к железу выполнено; обязательный путь работает на обычной машине.

## Последствия

Без LLM хуже разбор резюме на нестандартных шаблонах и тексты объяснений; ядро не страдает.
