# ADR-0006. Категория и грейд — только из теста

**Статус:** принято · **Область:** Тест

## Контекст

ТЗ требует, чтобы категория определялась обязательным путём «опрос → выбор грейда → тест», а не резюме; организаторы подтвердили: грейд только по тесту, ФСП — ранжирование внутри категории.

## Решение

Категория = профессия × грейд, подтверждённый тестом. Резюме, ФСП и задания категорию не задают: они формируют доверие к навыкам, силу профиля и объяснения. Грейд хранится на каждую профессию отдельно.

## Почему

Работодатель видит категории проверенных кандидатов; «заявлено vs подтверждено» видно в карточке.

## Последствия

Сигнальный грейд анкеты из старой модели остаётся только во внутреннем скоринге под вакансию (см. [matching.md](../mechanics/matching.md#9-ограничения-и-известные-отличия)).
