# ADR-0002. Python для всех сервисов, одно React SPA

**Статус:** принято · **Область:** Архитектура

## Контекст

ML на Python; бэкенду стек не важен. SEO не нужен, публичных страниц мало.

## Решение

Python 3.12 + FastAPI во всех сервисах, aiogram в боте, uv workspace. Фронт — одно SPA на React + Vite + TypeScript для всех ролей; публичные бейджи и OG-превью отдаёт бэкенд.

## Почему

Общие pydantic-контракты без кодогенерации между сервисами, OpenAPI из кода, клиент фронта генерируется из OpenAPI. Простой деплой статики.

## Последствия

Тяжёлый лендинг для SEO при необходимости — отдельно.
