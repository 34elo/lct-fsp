# ADR-0020. Доверие к навыку: noisy-OR источников и лестница доказательств

**Статус:** принято · **Область:** Навыки

## Контекст

Нужно отличать «написал в резюме» от «подтвердил тестом и на соревнованиях» и объяснять это работодателю.

## Решение

Доказательство «факт → навык» с силой по источнику (самооценка 0.15, резюме 0.25–0.40, тест ≤ 0.75, задание ≤ 0.5, ФСП ≤ 0.95), затухание по периоду полураспада источника. Внутри источника — максимум, между источниками — noisy-OR. Пять уровней ○○○○…●●●●. Потолок теста ниже порога уровня 4: высший уровень требует независимого подтверждения. Софт-навыки — только командные сигналы из фактов с ограниченным коэффициентом `K_soft`, без вывода качеств из текста, голоса или мимики. Граф навыков растёт: новые навыки — `provisional` со слабым доверием, связи — по совместной встречаемости.

## Почему

Каждая точка доверия объяснима списком доказательств; повторение одного источника не накручивает доверие.

## Последствия

Новый навык доходит до полного веса только после поддержки ≥ 5 кандидатов или решения администратора.
