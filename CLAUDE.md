## Claude Code

- **Вайбкодинг по плану:** `/vibe` — диспетчер сам идёт по очереди [plan.md §4](docs/process/plan.md) и отдаёт задачи сабагентам; работа на ветке `vibe`. Подробно — [workflow.md §7.5](docs/process/workflow.md#75-вайбкодинг-по-плану-vibe).
- **Задача из бэклога:** `/task <ID>` (например, `/task E7-1`). **Изменение контракта:** `/contract <что меняем>`. **Сверка документации с кодом:** `/docs-sync <область>`.
- **Больше одного файла** — сначала plan mode (Shift+Tab), план на подтверждение, потом код.
- **Модель:** Sonnet по умолчанию; Opus — архитектура, сложная отладка, ревью контрактов; Haiku — механические правки и поиск. Переключение: `/model`.
- **Контекст:** `/clear` между задачами; `/compact`, если сессия разрослась. Большие файлы и логи целиком не читай.
- **Сабагенты** — только для широкого поиска по коду (Explore). Каждый стартует с нуля и дорого стоит.
- **Перед PR** — `/code-review` по диффу.
