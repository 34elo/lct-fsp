# ФСП Карьера

Платформа найма в ИТ с **обратной механикой** для Федерации спортивного программирования. Работодатель не разбирает отклики: он описывает, кого ищет, видит **категории проверенных кандидатов** (профессия × грейд) и сам приглашает конкретного человека, сразу указывая вилку зарплаты. Контакты кандидата открываются только после его согласия.

**Стенд:** https://dashboard.fsp.patissons.tech · **API:** https://dashboard.fsp.patissons.tech/api/docs

## Как это работает

- **Категорию даёт тест, а не резюме.** Путь кандидата: опрос (направление, стек, формат, вилка) → сам выбирает грейд → тест на этот грейд. Резюме лишь предзаполняет опрос.
- **Тест не утекает и остаётся сопоставимым.** Каждый получает свои варианты: задание — это код-генератор с вычислимым ответом, вариант строится внутри вымышленной компании («мира»), сгенерированной по сиду. Сложность заданий измеряется на ответах людей (модель Rasch), грейд решает классификационный тест SPRT у порога — в среднем 13 заданий. Повышение — отдельным тестом по приглашению, смена грейда — не чаще раза в 90 дней.
- **Доверие к навыкам — лестница доказательств.** Самооценка ○○○○ → резюме ●○○○ → тест ●●○○…●●●○ → результаты ФСП ●●●●. Работодатель видит, чем подтверждён каждый навык, и расхождения «заявлено / подтверждено».
- **Работодатель приходит сам.** Запрос текстом → рекомендованные категории с числом кандидатов и медианой ожиданий → кандидаты по `0.6·соответствие + 0.4·сила профиля` с объяснением → интерес с вилкой → приглашение → контакты после принятия. Внутри категории выше те, у кого сильнее тест и есть результаты ФСП; кандидат без ФСП не штрафуется.
- **ФСП.** Реестр мероприятий и результатов у администратора федерации, привязка профиля одной кнопкой, интеграция за портом, готовым к FSP ID на Keycloak (мок реализует OAuth 2.0 + PKCE и OIDC).
- **Без GPU.** Тест, грейды, подбор и офферы — детерминированные формулы; LLM — сменный модуль только для извлечения и формулировок.

Кроме обязательного: отклики на вакансии, регулярные задания и задания в приглашениях, конструктор заданий, Telegram-бот, антисписывание без камер, «Объясни ответ», навигатор роста, Open Badge, поддержка кандидатов 15–17 лет, адаптивная вёрстка и тёмная тема.

## Демо-аккаунты

Пароль у всех — `demo-pass-1234`. Люди и компании вымышленные.

| Роль | Логин | Что посмотреть |
|---|---|---|
| Кандидат для проверки | `jury-candidate@demo.fsp.test` | Без грейда: опрос → экспресс-тест на 3–5 минут → категория; «Привязать ФСП» |
| Работодатель для проверки | `jury-hr@demo.fsp.test` | Проверенная компания: подбор, приглашение |
| Кандидат | `anya@demo.fsp.test` | История теста: Middle не прошла → Junior подтверждён |
| Кандидат | `boris@demo.fsp.test` | Backend без ФСП, приглашения и отклики |
| Кандидат | `gleb@demo.fsp.test` | Грейд с меткой «требует подтверждения» |
| Работодатель | `olga@demo.fsp.test` | «Северный код»: подбор, приглашения, задания |
| Администратор ФСП | `admin@demo.fsp.test` | Допуск заданий, модерация, реестр ФСП, профессии, аналитика |

На стенде кнопка «Демо для жюри» на лендинге создаёт каждому проверяющему свою пару «кандидат + работодатель». Полный список аккаунтов — [docs/operations/running.md](docs/operations/running.md#демо-аккаунты).

**Сквозной сценарий:** войти кандидатом → пройти опрос и экспресс-тест → получить категорию → войти работодателем → «python middle» в строке подбора → категория → кандидат → «Интересен» / «Пригласить» с вилкой → кандидатом принять → работодатель видит контакты.

## Запуск локально

Нужны Docker с Compose v2, `make` и [uv](https://docs.astral.sh/uv/).

```bash
make up-lite    # сборка, миграции, справочник навыков; без GPU и LLM; секреты генерируются сами
make seed       # демо-данные и аккаунты
```

Приложение — http://localhost:28080, Swagger — http://localhost:28080/api/docs. Остановка — `make down`. Профили с LLM, Windows без make, сброс демо — [docs/operations/running.md](docs/operations/running.md).

## Архитектура

```
web (React SPA) ─┐                        ┌─► PostgreSQL + pgvector · Redis · MinIO
                 ├─► gateway ─► core ─────┤
bot (aiogram) ───┘   (Caddy)  api·worker·  └─► RabbitMQ ◄─► ml (эмбеддинги, резюме, LLM опционально)
                              scheduler          ▲
                                                 └──► fsp-connector ◄─► реестр ФСП · fsp-mock (OAuth/OIDC)
```

Python 3.12 · FastAPI · SQLAlchemy 2 · FastStream + RabbitMQ · PostgreSQL 16 + pgvector · Redis · MinIO · React 19 + Vite + TypeScript · Tailwind 4 · aiogram 3 · Docker Compose · Caddy.
