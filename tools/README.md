# tools

Инструменты разработки, демо-данных и валидации. Запускаются из корня репозитория через `make` или `uv run`.

| Каталог / файл | Что делает | Команда |
|---|---|---|
| `seed/` | Демо-данные: кандидаты, компании, вакансии, офферы, результаты ФСП, герои демо с историей теста, вход жюри, реестр ФСП. Все люди и компании вымышленные, детерминировано по `SEED` | `make seed` |
| `synth/` | Синтетический рынок кандидатов и потребностей с разметкой релевантности (в том числе «приукрашивающие» резюме) | `make synth SPLIT=test` |
| `eval/` | Валидация подбора против BM25 на синтетическом рынке, полнота разбора резюме на обезличенном наборе, подбор весов (`tune.py`), генератор набора резюме (`gen_hh_resumes.py`) | `make eval` |
| `eval_assessment/` | Валидация теста: симуляция кандидатов с известным θ через настоящие формулы теста, утечка, списывание, LLM-кандидат | `make eval-assessment` |
| `metrics/` | Сводный отчёт всех офлайн-метрик со светофором | `make metrics` |
| `load/` | Нагрузочный сценарий Locust на живом стенде | `make load` |
| `libraries.py` | Список библиотек с версиями и лицензиями из lock-файлов → `docs/libraries.md` | `make libraries` |
| `check_links.py` | Проверка относительных ссылок и якорей в Markdown без сети | `make docs-links` |
| `tests/` | Тесты инструментов | `uv run pytest tools -q` |

## Демо-данные (`seed/`)

| Файл | Что |
|---|---|
| `config.yaml` | Объёмы витрины, пароль демо-аккаунтов, вымышленные компании и города |
| `plan.py`, `loader.py` | План витрины по сиду и загрузка в БД через сервисные слои core |
| `demo_v2.yaml`, `demo_v2.py` | Герои демо: история теста, отклики, офферы, регулярные задания |
| `heroes/*.yaml` | Профили героев (резюме, навыки, согласия, участник ФСП) |
| `grades.py` | Грейды демо-кандидатов без прохождения теста |
| `families.py` | Банк заданий в БД |
| `jury.py` | Аккаунты входа жюри |
| `fsp_registry.py`, `fsp_registry.yaml` | Участники и результаты реестра ФСП |
| `professions.py` | Демо «новая профессия» |

Отчёты всех инструментов пишутся в `reports/` (в git не входит).
