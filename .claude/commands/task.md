Задача: $ARGUMENTS из `docs/process/backlog.md`.

1. Найди строку задачи в бэклоге: что сделать, от чего зависит, критерий «готово». Работа идёт двумя блоками: прочитай `docs/process/blocks.md` §0 и §8, определи блок задачи по разделу `plan.md` §4.2 и проверь, что ты на ветке этого блока. Для `S0-*` и половин `a`/`b` описание — в blocks.md §11–12.
2. По таблице «Что читать под задачу» из AGENTS.md открой **только нужные разделы** документов. Целиком документы не читай.
3. Проверь, что зависимости задачи уже сделаны. Если нет — остановись и скажи, чего не хватает.
4. Дай план на 5–10 пунктов: какие файлы меняются, какие тесты появятся, какие документы нужно обновить. Жди подтверждения.
5. После подтверждения: код → тесты (`-q`) → линтер → обновление документов, если менялись контракты, схемы или формулы.
6. В конце доложи по формату из раздела «В конце задачи» AGENTS.md и предложи сообщение коммита.
