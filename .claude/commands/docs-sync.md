Область: $ARGUMENTS

1. Найди в `docs/architecture/` разделы про эту область (карта — `docs/README.md`).
2. Сравни с кодом: эндпоинты, схемы, таблицы, события, формулы, пороги.
3. Выведи список расхождений: «документ говорит X, код делает Y».
4. Для каждого предложи, что правильно: документ или код. Ничего не меняй без подтверждения.
5. После подтверждения правь документы точечно, новые файлы не создавай.
