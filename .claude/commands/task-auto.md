Задача: **$ARGUMENTS** (если ID пришёл в тексте промпта, бери его). Человек недоступен: не задавай вопросов, решай по документам.

1. **Пойми задачу.** Найди её строку в `docs/process/backlog.md` (что сделать, критерий «Готово, когда»). По таблице «Что читать под задачу» из `AGENTS.md` открой **только нужные разделы** документов (по заголовкам, не целиком).
2. **Проверь, можно ли делать.** Нужны секреты, доступы, железо, данные от людей, решение человека или нет кода из зависимостей → ничего не меняй и верни отчёт со статусом `БЛОКЕР` и причиной.
3. **Сделай минимально достаточно** для критерия «Готово». План держи в голове, подтверждения не жди. Без GPU работай с `ML_FAKE=true`. Не трогай зоны вне задачи, не рефактори лишнее, не добавляй лишних зависимостей.
4. **Тесты.** Напиши тесты по правилам AGENTS.md и запусти: `-q`, вывод через `tail`. Линтер. До 3 попыток починить.
5. **Документы.** Менял контракт, схему, таблицу или формулу — точечно обнови соответствующий раздел в `docs/architecture/`. Новые документы не создавай. **`docs/process/plan.md` не трогай**: статусы ставит диспетчер.
6. **Коммиты** на текущей ветке, только когда тесты и линтер зелёные. Conventional Commits с ID: `feat(core): E4-2 пересчёт доверия`. Не пушь, не создавай ветки.
7. **Режим 🤝 (черновик):** доведи до рабочего состояния и в отчёте перечисли, что должен проверить человек.

**Отчёт (не больше 15 строк):**
```
СТАТУС: ГОТОВО | ЧАСТИЧНО | БЛОКЕР
Задача: <ID> — <одна строка>
Сделано: …
Файлы: …
Проверка: <команда, которой диспетчер проверит результат>
Документы: <что обновлено или «не требовалось»>
Человеку проверить: … (для 🤝 и ЧАСТИЧНО)
Вопросы/блокеры: …
```

**Запрещено:** читать `.env`; `git push`, `reset --hard`, `clean`; внешние платные сервисы; менять `packages/contracts` сверх описанного в документах (если нужно — `БЛОКЕР` с предложением).
