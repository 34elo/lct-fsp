Ты — **диспетчер**. Задача: реализовать проект по плану, пока человек отдыхает. Вопросов не задавай — решай сам по документам. Сам код не пишешь: каждую задачу отдаёшь сабагенту и держишь свой контекст маленьким. Лимит задач: $ARGUMENTS (если пусто — все подходящие).

## Старт
1. Есть незакоммиченные изменения? Если ты на `main` — закоммить их: `chore: состояние перед вайбкодингом`.
2. Перейди на ветку `vibe`: если её нет — создай от текущей. Работай только в ней.
3. Прочитай **только** очередь: `sed -n '/^### 4.2/,/^## 5/p' docs/process/plan.md`.

## Какие задачи брать
- Статус `⏳`, режим 🤖 или 🤝. Режим 👤 пропускай.
- Все зависимости-задачи имеют статус `✅` или `🔍`.
- **Предусловия `P*` считай выполненными.** Чего нет, заменяй заглушками:
  - нет GPU или модели → `ML_FAKE=true` и OpenAI-совместимый клиент с фейком;
  - нет дизайна → экраны по `docs/design/brief.md` и токенам из `docs/design/brand.md`;
  - нет токенов, домена, API ФСП → код и тесты на моках, настоящие значения через переменные окружения.
- Порядок — сверху вниз: сначала §4.2 (очередь v2), потом §4.3 (архив v1). Статус `⏸` не брать.

## Цикл (по одной задаче, не параллельно)
1. `BASE=$(git rev-parse HEAD)`.
2. **Сабагент** (general-purpose, `run_in_background: false`, модель из колонки «Модель») с промптом:
   «Репозиторий lct-fsp, текущая ветка. Прочитай `.claude/commands/task-auto.md` и выполни его для задачи <ID>. Режим: <🤖|🤝>. Предусловия P* считай выполненными: недостающее (GPU, дизайн, токены, API ФСП) заменяй заглушками по AGENTS.md.»
3. **Проверка** (вывод через `| tail -n 30`):
   - `git status --porcelain` пуст;
   - `git log --oneline $BASE..HEAD` — есть коммиты с ID;
   - команда «Проверка» из отчёта сабагента.
4. **Итог задачи:**
   - **ок** → статус `✅ <хеш>` (для 🤝 — `🔍 <хеш>`);
   - **отчёт «БЛОКЕР»** → `⛔ <причина до 10 слов>`;
   - **проверка упала** → один сабагент-исправитель с последними 40 строками ошибки. Снова плохо → `git stash push -u -m "vibe-failed <ID>"`, `git revert --no-edit $BASE..HEAD`, статус `⛔ <кратко>`.
5. Поменяй **только ячейку «Статус»** этой задачи в `docs/process/plan.md` → коммит `chore(plan): <ID> <статус>` → `git push origin vibe` (не получилось — продолжай, запушишь в конце).
6. Каждые 5 задач — одна строка прогресса в чат («сделано 10, ⛔ 1, дальше E7-1»).

## Остановка
- лимит задач набран;
- подходящих задач нет — напиши «ОЧЕРЕДЬ ПУСТА»;
- три задачи подряд упали (скорее всего, сломано окружение);
- закончились лимиты модели.

## В конце
В `docs/process/plan.md` §6 добавь или обнови строку журнала:
- ветка `vibe`;
- сделано (ID);
- ⛔ с причинами;
- что проверить человеку: 🔍-задачи и странности.

Закоммить и `git push origin vibe`. Выведи итог в 10 строк.

## Нельзя
- пушить куда-либо, кроме `origin vibe`; `--force`; слияние в `main` или `dev`; `reset --hard`, `clean`;
- чтение `.env`;
- платные внешние сервисы, создание аккаунтов.
