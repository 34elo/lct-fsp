# @fsp/ui

Дизайн-система ФСП Карьеры: токены, тема Tailwind 4, базовые и фирменные компоненты. Пакет без сборки — `apps/web` импортирует исходники. Описание стиля — [design.md](../../docs/design.md).

| Каталог (`src/`) | Что |
|---|---|
| `styles/tokens.css` | CSS-переменные: цвета, шрифты, радиусы, тени, шкала текста; светлая тема в `:root`, тёмная в `.dark` |
| `styles/index.css` | `@theme inline` для Tailwind, базовые стили (`@fsp/ui/styles.css`) |
| `primitives/` | Кнопки, формы, оверлеи (Radix), отображение: Skeleton, EmptyState, ErrorState, NotFound |
| `brand/` | Фирменные: точки доверия, чипс навыка, бейдж грейда, протокол ФСП, обоснование совпадения, вилка, статусы оффера, шкала вероятности принятия, карточки кандидата и оффера |
| `v2/` | Каркас страниц, карточки, графики (SVG без библиотек), компоненты теста |
| `v3/` | Combobox и множественный выбор, поля навыков, профессии и вилки, Markdown и редактор, диаграммы Mermaid, граф доказательств, дорожная карта, скелетоны |
| `lib/` | `cn`, форматирование рублей, область темы |

## Команды

```bash
pnpm --filter @fsp/ui dev        # playground на http://localhost:28174: токены, базовые и фирменные компоненты
pnpm --filter @fsp/ui test
pnpm --filter @fsp/ui lint
pnpm --filter @fsp/ui typecheck
```

Правила: внутри пакета только относительные импорты; цвета, шрифты и радиусы — только из токенов. Контраст пар цветов проверяет `styles/contrast.test.ts`.
