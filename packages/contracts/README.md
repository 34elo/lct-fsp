# fsp-contracts

Общие pydantic-схемы для всех Python-сервисов: события, команды, DTO, перечисления. Единственный источник правды о межсервисном взаимодействии; из него генерируется [asyncapi.json](../../docs/asyncapi.json) (`make asyncapi`). Не зависит от `fsp-platform`.

| Модуль (`src/fsp_contracts/`) | Что |
|---|---|
| `envelope.py` | Конверт сообщения: `message_id`, `type`, `schema_version`, `producer`, `occurred_at`, `correlation_id`, `payload` |
| `events.py` | Доменные события и их реестр `EVENTS` |
| `commands.py` | Команды, очередь-получатель и приоритет (`COMMANDS`) |
| `enums.py` | Грейды, роли, форматы, статусы офферов, причины отказа, согласия, дисциплины и разряды ФСП, статусы компаний |
| `assessment.py` | Тест и категории: типы навыков, грейды теста, профессии, `CandidateGrade`, события попытки и категории |
| `hiring.py` | События офферов и интереса, инициатор, база вилки, способ связи |
| `fsp.py` | DTO ФСП: участник, результат, соревнование, разряд, команда |
| `ml.py` | DTO ml-api: резюме, запрос и фильтры, навыки, эмбеддинги, объяснения |
| `notify.py`, `ui.py` | Сообщения в Telegram и UI-шину |
| `analytics*.py` | Схемы событий аналитики |
| `registry.py` | Создание конвертов событий и команд |
| `asyncapi.py` | Генерация AsyncAPI |

Правило: добавлять можно, ломать нельзя. Ломающее изменение — новый `schema_version` или новое имя. Тесты — `tests/` (`uv run pytest packages/contracts -q`).
