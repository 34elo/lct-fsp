# AGENTS.md

Правила для ИИ-агентов и людей, работающих с репозиторием. Что за проект — [README.md](README.md), вся документация — [docs/README.md](docs/README.md).

## Где что

- `services/core` — модульный монолит (api, worker, scheduler); модули `app/<имя>/` с `README.md`.
- `services/ml`, `services/fsp-connector`, `services/fsp-mock`, `services/bot` — сервисы-спутники.
- `packages/contracts` — события, команды, DTO; `packages/platform` — общая инфраструктура; `packages/ui` — дизайн-система.
- `apps/web` — SPA; `data/` — справочники и `scoring.yaml`; `tools/` — демо-данные и валидация; `infra/` — запуск.

Под задачу читай только нужное: механики — `docs/mechanics/`, архитектура и API — `docs/architecture/`, запуск — `docs/operations/`, решения — `docs/adr/`.

## Правила

1. **Код — источник правды**; документация обновляется в том же изменении, что и поведение.
2. **Контракты первыми.** Меняешь API или событие — правь `packages/contracts`, перегенерируй `make openapi`, `make asyncapi`, `make api-gen`. Ломающее изменение — новый `schema_version` или новое имя.
3. **Границы.** Модули core общаются через `service.py`; ml, fsp-connector и bot не ходят в БД core — только события, команды и internal API.
4. **Детерминированное ядро.** Тест, доверие, сила профиля, подбор — формулы из `data/scoring.yaml`. LLM только извлекает данные и формулирует текст: ответ по JSON-схеме, затем проверка. В LLM ходим только через ml-api или очередь `ml.llm`.
5. **Приватность.** ПДн нет в логах, аналитике и промптах. Работодатель до принятия приглашения или отклика не получает контактов. Код кандидатов не исполняется.
6. **Надёжность сообщений.** Событие пишется в outbox в той же транзакции; обработчик идемпотентен (inbox).
7. **Секреты** — только в `.env`: не читать, не печатать, не коммитить.
8. **Тесты обязательны:** формула — пример из документации; эндпоинт — «чужой ресурс → 404»; обработчик — повторная доставка не меняет результат.
9. **Маленькие изменения** без рефакторинга вне задачи и без новых зависимостей без причины.

## Стиль

- Python 3.12, ruff, type hints, Pydantic v2, SQLAlchemy 2 async. Деньги — `int` ₽/мес, время — UTC, ошибки API — Problem Details с машинным `code`.
- TypeScript strict; данные — только через сгенерированный клиент (`apps/web/src/api` руками не правим); цвета и шрифты — из токенов `@fsp/ui`; экран проверяется на 375 px и в тёмной теме.
- Комментарии объясняют «почему», без ссылок на задачи и тикеты.
- Документация, UI и тексты бота — по-русски; код и идентификаторы — по-английски. Коммиты — Conventional Commits с описанием по-русски: `feat(core/offers): лимит приглашений в сутки`.
