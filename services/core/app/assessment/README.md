# Тест и грейды — `app/assessment`

Опрос, «мир» варианта, банк семейств, попытки с Rasch + SPRT, грейды и кулдауны, индекс честности, «Объясни ответ», конструктор, регулярные задания, жизненный цикл и допуск заданий, генерация LLM, майнинг мутаций, задачи ФСП. Публичное API для других модулей — только `service.py`.

| Файл | Что |
|---|---|
| `attempts.py` | попытка, выдача, ответ, этапы |
| `selection.py` | план, дефицит, счёт задания, пилоты |
| `engine.py` | фильтры банка поверх БД |
| `psychometrics.py` | Rasch, EAP, калибровка |
| `sprt.py` | SPRT и бонус |
| `grading.py` | кулдауны, грейд, доказательства `test`, события |
| `integrity.py` | индекс честности |
| `world.py` | «мир» варианта |
| `families/` | кодовые семейства, спецификации, автопроверка |
| `constructor.py` | конструктор заданий |
| `lifecycle.py` | статистика, допуск, тревоги |
| `tasks.py` | регулярные задания |
| `explain.py` | «Объясни ответ» |
| `llm_bank.py` | офлайн-генерация LLM |
| `orders.py` | заказ генерации из админки |
| `mining/` | мутации открытого кода |
| `fsp_bank.py` | задачи соревнований ФСП |
| `service.py` | публичное API модуля |

Подробнее: [assessment.md](../../../../docs/mechanics/assessment.md).
