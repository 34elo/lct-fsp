# Аналитика — `app/analytics`

События продукта по псевдонимам без ПДн (`/track` и доменные события через очередь `core.analytics`), воронки и онлайн-метрики для администратора, живые прогоны с участниками и опросником SUS.

| Файл | Что |
|---|---|
| `service.py` | псевдонимы, запись, партиции |
| `mapper.py` | доменное событие → события аналитики |
| `hiring.py` | события подбора |
| `dashboard.py` | дашборд ФСП |
| `metrics.py` | онлайн-метрики |
| `runs.py` | живые прогоны и SUS |
| `router.py` | `/track`, `/internal/track` |

Подробнее: [validation.md](../../../../docs/quality/validation.md).
