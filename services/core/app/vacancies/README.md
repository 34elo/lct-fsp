# Вакансии — `app/vacancies`

Вакансии с обязательной вилкой «от–до» и навыками; черновик → публикация → закрытие; публичный список и отклик. События `vacancy.*` запускают пересчёт подбора.

| Файл | Что |
|---|---|
| `router.py` | `/vacancies/*` |
| `service.py` | CRUD, публикация, фильтры публичного списка |
