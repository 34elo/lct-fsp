# Контакт: интерес, приглашение, отклик — `app/offers`

Единая сущность оффера: интерес, приглашение с вакансией или без, отклик кандидата; автомат статусов; лимиты и идемпотентность; раскрытие и отзыв контактов; переписка; задание в приглашении; командные приглашения; жалобы; «Почему вы».

| Файл | Что |
|---|---|
| `service.py` | создание, переходы (`transition`), раскрытие контактов, истечение |
| `router.py` | `/offers/*`, `/interests/*`, `/candidates/me/offers`, `/admin/complaints/*` |
| `why.py` | «Почему вы» и надёжность компании |
| `teams.py` | команды ФСП и командный оффер |
| `invite_task.py` | порт к банку заданий |
| `activity.py` | лента активности компании |
