# Подбор — `app/matching`

Потребность → категории → кандидаты по `rank = 0.6·match + 0.4·strength`; поиск по базе; подбор под вакансию со скорингом и объяснениями; переранжирование и MMR; `p_accept`; похожие; подписки на категории; сила и место кандидата; навигатор и uplift.

| Файл | Что |
|---|---|
| `needs.py` | affinity, рекомендация категорий |
| `needs_service.py` | потребности и счётчики категорий |
| `needs_router.py` | `/needs/*`, `/categories/*`, `/shortlist` |
| `search.py` | выдача и поиск: фильтры, сила, курсор, кеш |
| `strength.py` | сила профиля и rank |
| `scoring.py` | скоринг под вакансию, жёсткие фильтры, объяснения |
| `rerank.py` | множители и MMR |
| `p_accept.py` | вероятность принятия |
| `query_parser.py` | правиловый разбор запроса |
| `query_llm.py` | уточнение разбора LLM |
| `card.py` | расширенная анонимная карточка |
| `similar.py` | похожие кандидаты |
| `subscriptions.py` | подписки на категорию |
| `standing.py` | сила и место для кандидата |
| `navigator.py` | путь к следующему грейду |
| `uplift.py` | uplift навыков |
| `service.py` | видимость, подбор под вакансию, интересы кандидата |
| `router.py` | `/search/*`, карточка, навигатор, uplift |

Подробнее: [matching.md](../../../../docs/mechanics/matching.md).
