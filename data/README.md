# data

Данные, которые задают поведение системы. Код читает их напрямую; изменение — без правки кода.

| Путь | Что | Где используется |
|---|---|---|
| `scoring.yaml` | Все числа формул: тест (пороги, SPRT, план, честность, жизненный цикл заданий), доверие к источникам, сила профиля, подбор, `p_accept`, подстройка выдачи, лимиты | core: `assessment`, `graph`, `matching`, `offers` |
| `taxonomy/skills.yaml` | Навыки: slug, название, тип, синонимы, родитель | Справочник core (`make taxonomy-load`) |
| `taxonomy/roles.yaml` | Профессии и веса навыков | Справочник, план теста, категории |
| `taxonomy/relations.yaml` | Связи навыков: родитель с коэффициентом, смежность, пары «точно разные» | Наследование доверия, смежность в подборе |
| `taxonomy/package_map.yaml` | Библиотеки → навыки | Сопоставление стека |
| `taxonomy/skills_assessment.yaml` | Навыки мышления, бизнеса, софта, опыта, AI Engineer и типы навыков | Справочник, план теста |
| `skills/cards/*.yaml` | Карточки навыков: утверждения по уровням, понятия, заблуждения | «Объясни ответ», администратор (`make cards-check`) |
| `fsp/discipline_rules.yaml` | Дисциплина (и трек) ФСП → навыки с весами | Доказательства ФСП, релевантность |
| `questions/mutations/sources.yaml` | Открытые проекты для майнинга мутаций | `make assessment-mutations-mine` |
| `eval/resumes/hh/` | Обезличенные резюме в формате hh.ru и эталон `gold.json` | Валидация разбора резюме (`make eval`) |

Все люди и компании в данных вымышленные.
